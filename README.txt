ORGANIC WASTE TO WEALTH — STATIC MVP

Files:
- customer.html: Customer submission form and ticket lookup
- admin.html: Admin ticket list, review, status and verified payout
- farmer.html: Product catalogue and demonstration cart
- styles.css: Shared styling for all pages
- app.js: Shared JavaScript functionality

Run locally:
1. Keep all five files in the same folder.
2. Open customer.html in a modern browser.
3. Submit a test waste ticket.
4. Copy the generated ticket ID.
5. Open admin.html to review the ticket.
6. Open customer.html again and look up the ticket ID to see the updated status/payment.
7. Open farmer.html to test the demonstration cart.

Storage:
- Uses localStorage in the same browser and origin.
- Data is NOT synced across devices or browsers.
- Clearing browser storage removes the demonstration records.
- Uploaded images are resized/compressed before being stored.

AI honesty:
- The current classification is category-assisted: the customer chooses a category and the prototype displays it as the provisional classification.
- It does NOT run a trained AI image classifier.
- Do not present the placeholder as genuine AI inference.

Payments and products:
- All rates and product prices are illustrative.
- No real payments or orders are processed.
- The Allium pesticide is an R&D concept, not a product for actual use or sale.

GitHub Pages:
1. Create a GitHub repository.
2. Upload customer.html, admin.html, farmer.html, styles.css and app.js to the repository root.
3. In repository Settings > Pages, select deploy from branch and the main branch / root folder.
4. Save and use the generated GitHub Pages URL.
